# WRECK EARTH — 지도 위 어디든 진짜 물리로 부숴 봐

실제 지도(OpenStreetMap)와 실제 지형 높이로 지구 어느 곳이든 3D 도시를 만들고, 물리 엔진으로 건물을 부수는 Windows 데스크톱 게임입니다. 설치 없이 실행되는 exe 하나로 동작합니다.

## 다운로드

[Releases](../../releases/latest)에서 받으세요.

- `WreckEarth-x.y.z-portable.exe` — 더블클릭으로 바로 실행 (설치 없음)
- `WreckEarth-x.y.z-win.zip` — 압축을 풀고 `WreckEarth.exe` 실행

Windows 10/11 64비트용입니다. 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

## 특징

- **어디든 불러오기** — 지명·주소·좌표로 검색하면 그 자리의 건물, 도로, 공원, 숲, 강, 지형 높낮이를 받아 3D로 만듭니다. 한 번 받은 지역은 PC에 저장돼 다음부터 바로 열립니다.
- **진짜 물리 파괴** — 건물을 수십~수백 개 조각으로 나눠 [Rapier](https://rapier.rs) 물리 엔진으로 시뮬레이션합니다. 기둥이 끊긴 층 위는 기울며 넘어지고, 무너지는 무게가 아래층을 연달아 짓눌러 바닥까지 내려앉습니다.
- **무기 42종, 7개 분류**
  - 폭발: 폭탄, 미사일, 집속탄, 열압력탄, 네이팜, 레일건
  - 공습: 융단폭격, 벙커버스터, 순항미사일, 자폭 드론 떼, 함포 사격
  - 하늘: 궤도 레이저, 운석우, 신의 지팡이, 소행성 충돌, 외계 모선, 태양 렌즈, 번개 폭풍
  - 자연재해: 지진, EF5 토네이도, 싱크홀, 쓰나미, 화산, 산사태, 빙하기
  - 특수: 블랙홀(완전 흡수 옵션), 화이트홀, 반중력, 중력 반전, 시간 역행
  - 놀이·괴수: 철거 철구, 거대 볼링공, 도미노, 신의 손가락, 괴수 발, 바위 거인, 폭주 기차
  - 핵: 핵폭탄, 폭격기 투하, ICBM(다탄두 옵션), 차르 봄바, 반물질 폭탄
- **큰 무기는 카메라 연출** — 접근·발사·착탄을 여러 각도로 보여 주고, 클릭이나 Esc로 언제든 건너뜁니다. "연출 카메라" 옵션으로 끌 수 있습니다.
- **위력 ×1 ~ ×100** — ×1은 약하게, ×10은 세게, ×100은 세계 멸망급. 핵은 실제 위력 기준으로 ×1 ≈ 15kt(히로시마), ×10 ≈ 0.84Mt, ×100 ≈ 47Mt(차르 봄바급)이고, 피해 반경도 실제 핵무기 상사법칙(위력의 1/3제곱)으로 계산합니다. ×100에서는 지도 전체가 증발하고 수십 km 높이의 버섯구름, 지평선까지 퍼지는 충격파, 붉게 타는 하늘과 낙진(핵겨울)이 이어집니다.
- **실감 핵 연출 (켜고 끄기)** — 섬광, 식어가는 화구, 응결운, 버섯구름, 지면 충격파, 거리만큼 늦게 오는 굉음.
- **물리는 별도 스레드** — 물리 계산을 화면 그리기와 다른 스레드(Web Worker)에서 돌려 큰 폭발 직후에도 화면이 덜 멈춥니다. 받침이 사라진 파편은 다시 떨어지므로 공중에 떠 있는 잔해가 남지 않습니다.
- **그래픽** — 실시간 그림자, 셰이더로 그린 창문(밤에는 불이 켜짐), 하늘과 구름, 불꽃 빛번짐, 크레이터와 그을음. 시간대 4가지(아침·한낮·노을·밤), 품질 4단계.
- **오프라인 데모 시티** — 인터넷 없이도 절차 생성 도시에서 바로 플레이.
- 반경 300m ~ 3km, 슬로모션, 스크린샷(사진 폴더 `WreckEarth`에 저장), 장소별 최고 기록, F3 성능 정보.
- PC 성능에 맞춰 동시에 움직이는 파편 수를 자동으로 조절해 큰 폭발 직후에도 끊김을 줄입니다.

## 직접 빌드

```bash
npm ci
npm start          # 개발 실행 (Electron)
npm test           # 조각화·물리·핵 위력 테스트
npm run dist       # Windows exe/zip 빌드 → dist/ (npm run bundle 이 물리 워커를 앱 번들 안에 넣음)
```

### 릴리스 방법

`package.json`의 `version`을 올리고, 커밋 메시지에 `[release]`를 넣어 `main`에 푸시하면 GitHub Actions가 Windows에서 exe를 빌드해 릴리스를 만듭니다. **이 워크플로는 기존 릴리스와 태그를 모두 지우고 새 릴리스 하나로 교체합니다.** Actions 탭의 *Release* 워크플로에서 직접 실행할 수도 있습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `electron/` | 메인 프로세스(창, 지도·지형·검색 요청, 디스크 캐시, 스크린샷), 프리로드 |
| `src/geo.js` | 좌표 변환, Overpass 쿼리, OSM 파싱(멀티폴리곤 포함), 건물 높이 추정 |
| `src/terrain.js` | AWS Terrarium 지형 타일 → 높이맵, 크레이터, 강바닥 파기 |
| `src/fracture.js` | 건물 외피와 조각(정육면체에 가깝게 자른 각기둥) 생성 |
| `src/physics/` | 물리 워커(`worker.js`), 공용 Rapier 코어(`core.js`), 메인 스레드 창구(`physics.js`, 워커를 못 쓰면 같은 스레드로 대체) |
| `src/destruction.js` | 구조 지지·연쇄 붕괴, 폭발·회오리·중력장, 파편 예산, 레이캐스트, 대규모 붕괴·시간 역행 |
| `src/weapons/` | 무기 정의·모델·엔진(`arsenal.js`)과 분류별 구현(`classic`, `extra`, `air`, `sky2`, `storms`, `nature2`, `special2`, `fun`, `nukes`), 연출 샷 도우미(`cam.js`) |
| `src/cinematic.js` | 시네마틱 카메라 (건물에 가리면 앞으로 당겨 옴) |
| `src/fx.js` · `src/audio.js` | 파티클 연출, 실시간 합성 효과음 |
| `src/world.js` · `src/materials.js` | 지면 텍스처, 물, 나무, 창문 셰이더 |
| `src/game.js` · `src/app.js` | 렌더링 루프, 후처리, 카메라, 메뉴·HUD |
