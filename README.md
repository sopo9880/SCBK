# WRECK EARTH — 지도 위 어디든 진짜 물리로 부숴 봐

실제 지도(OpenStreetMap)와 실제 지형 높이로 지구 어느 곳이든 3D 도시를 만들고, 물리 엔진으로 건물을 부수는 Windows 데스크톱 게임입니다. 설치 없이 실행되는 exe 하나로 동작합니다.

## 다운로드

[Releases](../../releases/latest)에서 받으세요.

- `WreckEarth-x.y.z-portable.exe` — 더블클릭으로 바로 실행 (설치 없음)
- `WreckEarth-x.y.z-win.zip` — 압축을 풀고 `WreckEarth.exe` 실행

Windows 10/11 64비트용입니다. 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

- **큰 무기는 카메라 연출** — 접근·발사·착탄을 여러 각도로 보여 주고, 클릭이나 Esc로 언제든 건너뜁니다. 연출은 게임 시간에 맞춰 흘러서 슬로모션 중에도 사건과 어긋나지 않고, 건물에 가리면 카메라가 알아서 비켜 섭니다.
- **위력 ×1 ~ ×100** — ×1은 약하게, ×10은 세게, ×100은 세계 멸망. 핵은 실제 위력 기준으로 ×1 ≈ 15kt(히로시마), ×10 ≈ 0.84Mt, ×100 ≈ 47Mt(차르 봄바급)이고, 피해 반경도 실제 핵무기 상사법칙으로 계산합니다.
- **모든 무기의 ×100 = 세계 멸망** — 무기마다 그 무기다운 결말(연쇄 폭발, 하늘을 덮는 편대, 운석 폭풍, 지각 붕괴, 전 지구 해일, 행성이 삼켜짐…)이 지도 전체와 지평선 너머 마을까지 쓸어버리고, 종말 날씨(핵겨울·화산 겨울·얼음·보랏빛 하늘 등)가 이어지며, 마지막에 카메라가 우주까지 빠져 행성이 불타거나 갈라지거나 산산조각 나는 장면으로 끝납니다(설정에서 끌 수 있음).
- **실감 핵 연출 (켜고 끄기)** — 섬광, 식어가는 화구, 응결운, 버섯구름, 지면 충격파, 거리만큼 늦게 오는 굉음.
- **조각 수만 개** — 큰 조각은 별도 스레드의 정식 물리(Rapier SIMD)로, 작은 파편은 땅·건물에만 부딪히는 가벼운 물리로 계산해 조각 3만 개 이상, 동시에 움직이는 파편 1만 개 이상을 다룹니다. 받침이 사라진 파편은 다시 떨어져 공중에 떠 있는 잔해가 남지 않습니다.
- **발사 관제실 (L 키)** — 전술 지도에서 표적을 찍고 무기를 고른 뒤, 안전 덮개 → 발사 열쇠 → 발사 버튼 길게 누르기로 쏩니다. 가운데에는 실시간 화면이 보입니다.
- **탈것 직접 조종 (V 키)** — 자동차, 헬기, 경비행기, 전투기, 폭격기를 골라 도시 위를 달리거나 날 수 있어요. 조작은 GTA5 PC 기본 배치를 따르고(넘버패드가 없으면 I/K/J/L), 마우스로 카메라를 둘러봐요. 탈것마다 엔진 소리가 나요. 비행기는 지도 밖에 깔리는 활주로에서, 헬기는 옥상 헬리패드에서 출발할 수 있고, 천천히 내려오면 착륙해요(거칠면 튕기며 손상, 너무 거칠면 추락). 자동차는 차체 크기만큼 닿은 곳만 부서져요. 헬기는 부딪히면 손상되고 내구도가 0이 되면 빙글빙글 돌며 추락해요.
- **직접 조종하는 유도 미사일** — 발사하면 미사일 시점으로 바뀌고, 마우스나 WASD로 방향을 틀고 Shift로 가속, 클릭으로 기폭합니다.
- **세계 멸망 설정** — 끄고 켤 수 있고, 시작 조건을 위력(×75 이상) 또는 파괴율 기준으로 고를 수 있습니다. 무기 연출이 끝나면 "세계 멸망 3·2·1" 카운트다운 뒤 결말 연출과 행성 장면이 끊김 없이 이어지고, 그 사이 다른 무기를 쏘거나 Esc를 누르면 취소됩니다.
- **설정 페이지** — 그래픽(해상도·그림자·오클루전·계단 현상 제거·안개·나무·파티클), 빛·색감(화면 공간 반사·유리창·물 반사·빛번짐·노출·톤 매핑·채도·대비·비네트·연출 초점 흐림), 물리(조각 수 상한·세밀도·정확도), 카메라(시야각·감도·연출), 소리, 화면 안전(섬광·흔들림·번개 깜빡임), 조작 키 바꾸기, 데이터. 메뉴와 게임 중(O 키) 어디서나 열립니다.
- **지도 밖 세계** — 지평선까지 산과 먼 도시들이 이어져 멀리서 봐도 지도가 떠 있지 않고, 거대한 충격파는 지평선 너머 마을까지 쓸어버립니다.
- **그래픽** — 실시간 그림자, 셰이더로 그린 창문(밤에는 불이 켜짐), 밤의 가로등·차 불빛·항공 장애등, 하늘과 구름, 불꽃 빛번짐, 크레이터와 그을음. 시간대 4가지(아침·한낮·노을·밤), 품질 4단계.
- **바로 가는 장소** — 부산대학교, 동아대학교 승학캠퍼스, 연세대학교 신촌캠퍼스, 서울대학교, KAIST, 광화문, 해운대 등 자주 찾는 곳은 시작 화면에서 한 번에 고를 수 있습니다.
- **오프라인 데모 시티** — 인터넷 없이도 절차 생성 도시에서 바로 플레이. 부도심 다섯 곳과 강 두 줄기가 있는 **8×8km 메가 시티**(건물 약 1만 3천 동)도 있습니다.
- 반경 300m ~ 3km, 슬로모션, 스크린샷(사진 폴더 `WreckEarth`에 저장), 장소별 최고 기록, F3 성능 정보.
- PC 성능에 맞춰 동시에 움직이는 파편 수를 자동으로 조절해 큰 폭발 직후에도 끊김을 줄입니다.

## 직접 빌드

```bash
npm ci
npm start          # 개발 실행 (Electron)
npm test           # 조각화·물리·가벼운 파편·핵 위력·설정 테스트
npm run dist       # Windows exe/zip 빌드 → dist/ (npm run bundle 이 물리 워커를 앱 번들 안에 넣음)
```

### 릴리스 방법

`package.json`의 `version`을 올리고, 커밋 메시지에 `[release]`를 넣어 `main`에 푸시하면 GitHub Actions가 Windows에서 exe를 빌드해 릴리스를 만듭니다. 이전 버전의 릴리스는 그대로 남고, 같은 버전 번호로 다시 릴리스할 때만 그 버전을 새로 만듭니다. Actions 탭의 *Release* 워크플로에서 직접 실행할 수도 있습니다.
